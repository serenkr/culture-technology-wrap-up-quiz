# GCT501 Exam Room — Introduction to Culture Technology

GCT501 기말 대비 퀴즈. `index.html` 하나로 동작하고, GitHub Pages(Settings → Pages → Deploy from branch `main` / root)를 켜면 링크로 PC·모바일 어디서든 풀 수 있습니다.

## 구성
- 지난 실제 시험 순서: **Part I 객관식 → Part II 단답형 → Part III 인물 매칭 → Part IV 서술형**
- 형식 4가지: 실전형(객관식 15·단답 6·매칭 2·서술 2·사진 서술 1), 빠른 연습(10·4·1·1), 지난 형식(객관식 20·서술 4·사진 서술 1), 사진 서술만(3)
- 사진 서술: 사진 4~5장(철학자·기계·그림·박물관 건물 등)을 시간 순서로 놓고 사진마다 역사적 흐름 속 의미를 설명. 순서 20점 + 사진별 핵심 요소 80점, 사진마다 정답·첨삭·원문 표시
- 난이도 초급/중급/고급, 범위 토글(전체 / Wrap-up·강의노트에 나온 것만)
- 문제은행: 객관식 275(그림 문제 24 포함) · 단답 61 · 인물 118명 · 서술 25 · 사진 서술 11
- 출제 범위: 강의 01·02·03·05·06·07·08·09·10, Lecture Wrap-up, 문화기술론 강의노트만. (04 Visualization은 PDF가 없어 Wrap-up·노트 내용으로만 출제)
- 모든 문항에 원문 인용, 출처 페이지, 관련 슬라이드 이미지(Wrap-up/노트 페이지 포함)
- 인물 매칭: 사진(슬라이드에서 잘라낸 것)과 이름을 보고 업적과 선으로 연결. 오른쪽에 함정 보기 1개. 사진이 슬라이드에 없는 인물은 이니셜로 표시, 작품·장치 사진이면 그렇게 표시
- 서술형: 핵심 요소 체크, 내 답안 첨삭 하이라이트, 모범답안에서 빠뜨린 개념 빨간색 표시
- 오답노트: 개념·인물 먼저, ×로 삭제, 유형/강의 필터, 오답만 다시 풀기(인물은 매칭으로 재출제), 전체 비우기, JSON 백업/불러오기
- 강의자료: 압축한 PDF 11개를 AES-256으로 암호화해 저장. 비밀번호를 넣으면 브라우저에서 복호화해 내려받음
- 저장 키는 `gct501-exam-v2`라 같은 github.io 주소의 museumtology 퀴즈 기록과 섞이지 않음

## 이전(ChatGPT) 버전 검토 메모
이전 커밋(f700f83)의 버전에서 바꾼 점:
- 매칭 문제의 정답이 모두 `A–1, B–2, C–3, D–4, E–5`로 같아서 내용을 몰라도 맞힐 수 있었음 → 실제로 선을 잇는 이분매칭 + 함정 보기로 교체
- 강의별 편중(05: 2문항, 06: 1문항, 07: 6문항) → 강의별로 고르게 뽑는 층화 추출, 모든 강의에서 최소 28문항
- 출처 표기가 코드/파일명으로 섞여 있었고, 서술형 모범답안이 슬라이드 표현과 달랐음 → 원문 그대로 인용 + 페이지 표기
- 3MB base64 data.js → 이미지를 파일로 분리해 첫 로딩을 가볍게
- 유지한 것: 로컬 저장, 백업/복원, Wrap-up 우선 범위
